## Finder's fix sketch
Make 'put somewhere new' a property of the rest point's own jump, not of the Held state: keep the last rest point in FootHold, and at the top of HoldFoot (after the striking case), if the rest point moved more than SnapDrift x size since the last call, set Held = true, Stepping = false, Anchor = rest and return rest. No walk, dash or knockback in the data moves a man 1 m in a frame (the fastest is the dash, about 8.2 m/s, 27 cm at 30 Hz), and a From-to-rest distance test would misfire on the Runner, whose step legitimately spans about 1 m. The hips' drop can keep easing; nothing else holds a place.
